# 用户画像模块（G 阶段）

用户自填事实、授权平台事实与 AI 推断必须分层保存。AI 不覆盖原始事实，所有推断先进入 `candidate_inferences_requiring_confirmation`；只有用户逐项确认或修改后，画像才能从 `pending_user_confirmation` 变为 `confirmed` 并进入 Opportunity Score。

当前候选画像保存在 `data/profile_edwinayyy_candidate.json`，当前可见笔记样本保存在 `data/xiaohongshu_visible_posts.json`。平台数字是二〇二六年九月六日授权页面快照，不代表长期结果；小红书“获赞与收藏”是平台四舍五入后的合并展示值，不能拆成点赞和收藏，也不能视为精确整数。

## 当前采集结果

- 小红书：账号名、账号号、简介、关注、粉丝、获赞与收藏合计、部分标题和页面展示互动；主页未显示笔记总数，因此该字段为空。
- 画加：一期使用公开市场画师、橱窗列表与详情快照，不要求用户绑定个人画加账号。
- 米画师：已有账号数据仅作为历史用户资料留档，不再作为一期市场分析输入。
- 未采集图片和视频内容；未保存客户身份、聊天原文、订单详情或登录信息。

## 确认机制

用户必须确认：核心商业定位、账号阶段、内容支柱。任何一项未确认时，评分流程应阻断；修改后生成新 `profile_version`，旧版本保留用于结果追溯。
